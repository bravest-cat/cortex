# Cortex Journal & Episodic Audit Trail

This directory stores human-readable daily logs and architectural invariants generated by Cortex.

- **`invariants.md`**: Architectural rules and system invariants inducted from codebase reflections and dream mode cycles.
- **`YYYY-MM-DD.md`**: Automatically created by `record_system_outcome` when decisions, bug fixes, or milestones are recorded.
- **`dreams/`**: Consolidation reports produced during on-demand Dream Mode runs.
- **`archive/`**: Pruned and superseded facts archived during synaptic pruning cycles.
